# TSDB Explorer

[![License](https://img.shields.io/badge/License-MIT-blue.svg)](https://opensource.org/license/mit)

**A Qt-based data acquisition, visualization, and analysis tool for time series databases, inspired by oscilloscope UX.**

> [!IMPORTANT]
> **🚧 Early Development** - This is an experimental project with no clearly defined roadmap yet.\
> As we speak, its main purpose is to explore different approaches to TSDB interaction and learn along the way.\
> Features and architecture may change significantly as development progresses.\
> Any feedback or new ideas are always welcome!
